# Парсер сайта Alkoteka

Scrapy-паук для сбора данных о товарах с сайта alkoteka.com.

## Заметки о реализации и потенциальные улучшения
- Так как по условиям тестовое задание выполняется только на Scrapy (без использования  Playwright,
    Headless, Selenium и тд), а сайт динамически отображает товары, парсинг ведется в основноп по API сайта
- Указанные в тестовом задании "view360", "video", "variants", отсутствуют на сайте и в данных апи,
    поэтому в результатах представляют собой заглушку
- Так как это тестовое подразумевается как "небльшое", вот мои мысли по поводу того что можно улучшить.
-- Провести рефакторинг кода, в частности format_product_data. Следует разбить для читаемости на подфункции
-- Также нужна работа над логами. Чтобы лучше понимать сколько мы уже спарсили и сколько осталось
-- Как и предлагается в задании, использовать прокси, будет хорошим решением.
    Также можно изучить ограничения на сайте, чтобы избежать блокировки
-- Добавление БД и запись товаров в нее. Сможемь контролировать внезапное прерывание работы программы
    и перезапускать ее, игнорируя уже записанные товары

## Требования

- Python 3.8+
- Scrapy

## Установка

1. Склонируйте репозиторий, создайте виртуальное окружение:

2. Установите зависимости:
```bash
cd alcoteka_scraper/
pip install -r requirements.txt
```

## Конфигурация

Перед запуском укажите UUID вашего региона в файле `alkoteka/spiders/constants.py`:
```python
CITY_UUID = 'ваш-uuid-региона'  # Замените на реальный UUID для вашего региона. Изначально стоит Краснодар
```
Также можно обновить страницицы для парсинга
```
START_URLS = [
    'https://alkoteka.com/catalog/...',
    'https://alkoteka.com/catalog/...',
    'https://alkoteka.com/catalog/...',
    ...
]
```

## Запуск парсера

### 1. Базовый запуск (парсинг категорий по умолчанию)
```bash
scrapy crawl alkoteka -O result.json
```

### 2. Запуск с указанием файла URL-ов (по одному URL на строку)
\alcoteka_scraper\urls.txt
```bash
scrapy crawl alkoteka -a urls_file=urls.txt -O result.json
```

### 3. Дополнительные опции:

- Для сохранения в другие форматы:
```bash
scrapy crawl alkoteka -O result.jl  # JSON Lines
scrapy crawl alkoteka -O result.csv  # CSV
```

- Для увеличения скорости парсинга (осторожно, может привести к блокировке):
```bash
scrapy crawl alkoteka -s CONCURRENT_REQUESTS=8 -s DOWNLOAD_DELAY=0.5 -O result.json
```

## Особенности реализации

1. **Оптимизации:**
   - Загрузка всех товаров категории одним запросом
   - Кэширование HTTP-запросов
   - Модульная структура кода

2. **Обработка ошибок:**
   - Автоматический повтор при ошибках 429 (Too Many Requests)
   - Логирование ошибок парсинга

3. **Формат выходных данных:**
   - Сохраняет данные в JSON с полной структурой товаров
   - Поддерживает все основные поля (цены, наличие, изображения и т.д.)
